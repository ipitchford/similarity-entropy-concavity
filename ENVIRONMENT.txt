Release replay environment (24 November 2026, macOS arm64 host)
Interpreter: CPython 3.12.11 (uv-managed: `uv run --no-project --python 3.12 [--with ...] python`; the version was
printed inside the run with sys.version). Note: on this host `uv run --python 3.12 python3` can resolve to CPython 3.14
through a `python3` shim; the release replay therefore invoked `python` inside uv and recorded the actual version.
Packages: classify.py, verify.py, verify_mixing.py and check_classifier.py use the Python standard library only
(fractions, itertools, collections, math, json, argparse, pathlib). verify_independent.py needs sympy==1.14.0;
check_extensions.py needs sympy==1.14.0 and mpmath==1.3.0; figure.py needs numpy==2.3.5 and matplotlib==3.10.8
(requirements.txt).
Working directory: code/ (check_classifier.py and check_extensions.py import classify from their own folder, so they
run without -I).
GitHub CI: ubuntu-latest, actions/setup-python 3.12; every certificate script runs under python -O.
Cross-platform comparison (declared before tagging; same policy in CI, README.md and REPLAY_RECEIPT.md):
- Certificate arithmetic is exact (Python integers, fractions.Fraction, SymPy polynomials over ZZ and symbolic
  expressions). results/verify.txt, verify_independent.txt, verify_mixing.txt, check_classifier.txt and
  classify-five-state.json are compared byte for byte; none contains an interpreter version.
- results/extensions.json: exact values (integers, rationals and symbolic expressions as strings, booleans, structure)
  are compared exactly; floating-point fields (the mpmath asymptotic table computed at 50 digits, and printed float
  summaries: root, interval_width, nonconcave_and_positive_definite_interval, minimum_float) are compared to a relative
  tolerance of 1e-9 (declared tolerance of the script); an interpreter field, if present, is excluded.
- figures/mixing-example.pdf: regenerated by figure.py; only the embedded /CreationDate differs between runs.
